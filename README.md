# Celestial-Rays
Experimental real-time celestial body simulation and renderer built with Vulkan in C++ using a custom GLSL ray-tracer.

## Demo
Features a miniature version of our own solar system.

### Installation:
1. Download the Celestial-Rays-Demo.exe installer from the Demo release.
2. Run the downloaded installer to install the demo.

### Controls:
- WASD + EQ -> forward/left/backward/right + up/down camera movement
- Mouse -> Rotate camera
- Space -> pause/unpause the simulation
- Left Shift (hold) -> increase camera movement speed
- Left Control (hold) -> decrease camera movement speed
- Left Alt (hold) -> unlock mouse cursor/disable camera rotation
